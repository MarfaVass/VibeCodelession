# VibeCodelession

Учебный репозиторий курса «Профессия: вайб-кодинг» от Зерокодера.

## Проект: проверка карточек товара

Небольшая Python-программа для автоматической проверки обязательных полей карточки товара. Проект создан в рамках домашнего задания по работе с Git и GitHub.

### Что проверяет программа

- Наличие названия товара.
- Корректность цены: цена должна быть больше нуля.
- Наличие описания товара.

Если обнаружены ошибки, программа выводит список замечаний. Если все поля заполнены корректно, сообщает об успешной проверке.

### Требования

- Python 3.12 или совместимая версия Python 3.
- Дополнительные библиотеки для проверки карточки не требуются.

### Как запустить

Из корневой папки проекта выполните команду:

```bash
python main/main.py
```

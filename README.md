# VibeCodelession

Учебный репозиторий курса «Профессия: вайб-кодинг» от Зерокодера.

## Проект: проверка карточек товара

Небольшая Python-программа для автоматической проверки обязательных полей карточки товара. Проект создан в рамках домашнего задания по работе с Git и GitHub.

### Что проверяет программа

- Наличие названия товара.
- Корректность цены: цена должна быть больше нуля.
- Наличие описания товара.

Если обнаружены ошибки, программа выводит список замечаний. Если все поля заполнены корректно, сообщает об успешной проверке.

### Требования

- Python 3.12 или совместимая версия Python 3.
- Дополнительные библиотеки для проверки карточки не требуются.

### Как запустить

Из корневой папки проекта выполните команду:

```bash
python main/main.py
```

### Возможное развитие

В дальнейшем можно добавить проверку длины названия, формата цены и других требований к карточкам товара.

## PDF Studio (`pdf_studio/`) — развитие проекта

Графическое приложение на Tkinter с тем же механизмом генерации
(Jinja2 → WeasyPrint → автоматическое открытие PDF): выбор типа документа
в окне программы. Все три сценария реализованы: сертификат, отчет о продажах и коммерческое предложение по каталогу CSV.

Запуск (PowerShell из корня репозитория):
`.\venv\Scripts\python.exe pdf_studio\app.py`

Подробная инструкция и структура файлов — в `pdf_studio/README.md`.
Консольный скрипт `pdf_checkmaker/pdf_generator.py` сохранен без изменений
и продолжает работать как раньше.

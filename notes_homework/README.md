# 📝 Notes — консольный менеджер заметок

Учебный Python-проект: консольное мини-приложение для добавления, просмотра и удаления заметок. Проект написан в двух версиях — сначала как монолитный скрипт, затем перестроен в модульное приложение из трёх файлов.

Отчёт по работе: [`reports/homework_08_notes/homework_08_notes.md`](../reports/homework_08_notes/homework_08_notes.md) (со скриншотами кода и работы программы).

## О проекте

Notes — терминальное приложение с меню, работающее в бесконечном цикле до выбора пункта «Выход». Заметки хранятся в списке `list` в памяти: каждая заметка — строка текста. Данные не сохраняются между запусками программы.

Проект развивался в два этапа:

- **Этап 1 — монолит (`notes.py`).** Весь код в одном файле: данные, логика и интерфейс вместе.
- **Этап 2 — модульное приложение.** Код разделён на три файла с чётким разделением обязанностей: данные (`database.py`), логика (`utils.py`) и интерфейс (`main.py`).

## Возможности

| Функция                | Описание                                                            |
| ---------------------- | ------------------------------------------------------------------- |
| Добавить заметку       | Ввод строки текста, добавление в список с присвоением номера        |
| Показать все заметки   | Нумерованный вывод всех заметок в терминале                         |
| Удалить по номеру      | Удаление выбранной заметки после показа списка                      |
| Обработка ошибок ввода | Пустая заметка, не число, номер вне диапазона, пустой список        |
| Меню в цикле           | Программа не завершается без явного выбора пункта «Выход»           |

## Технологии

- **Python** — консольный интерфейс и логика приложения.
- Только стандартная библиотека — внешних зависимостей нет.

## Структура проекта

```text
notes_homework/
├── database.py    # только данные: список notes_db = []
├── utils.py       # логика: add_note, show_notes, delete_note
├── main.py        # точка входа: меню, input, вызовы функций
├── notes.py       # монолитная версия (этап 1), оставлена для сравнения
└── README.md
```

### Разделение по слоям

| Файл           | Слой        | Что содержит                                                            |
| -------------- | ----------- | ----------------------------------------------------------------------- |
| `database.py`  | Данные      | Список заметок `notes_db`, никакой логики                               |
| `utils.py`     | Логика      | Функции работы с заметками и проверки; импортирует `notes_db`           |
| `main.py`      | Интерфейс   | Меню, `input`, разбор ввода пользователя; импортирует функции           |

Разделение проверено: `utils.notes_db is database.notes_db` → `True`, то есть обе функции работают с одним и тем же списком из `database.py`, а не со своими копиями.

## Запуск проекта

Требуется установленный Python 3. Внешние зависимости не нужны, достаточно перейти в папку и запустить точку входа.

Из корневой папки репозитория:

```powershell
cd notes_homework
```

Запуск модульной версии:

```powershell
python main.py
```

Запуск монолитной версии:

```powershell
python notes.py
```

## Меню приложения

| Пункт  | Действие                    |
| ------ | --------------------------- |
| `1`    | Добавить заметку            |
| `2`    | Вывести все заметки         |
| `3`    | Удалить заметку по номеру   |
| `4`    | Выход                       |

### Проверки на ошибки

Приложение корректно обрабатывает некорректный ввод и не падает:

| Ситуация                                       | Реакция приложения                                  |
| ---------------------------------------------- | --------------------------------------------------- |
| Пустая строка при добавлении                   | «Заметка не может быть пустой»                      |
| Буквы вместо номера при удалении               | «Нужно ввести целое число»                          |
| Номер вне диапазона (например, `0` или `99`)   | Сообщение с допустимыми номерами `1–N`              |
| Удаление при пустом списке                     | «Список заметок пуст — удалять нечего»              |
| Просмотр пустого списка                        | «Список заметок пуст»                               |
| Неизвестный пункт меню                         | «Нет такого пункта, введите число от 1 до 4»        |

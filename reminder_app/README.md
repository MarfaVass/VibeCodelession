# Напоминалка

Десктопное приложение на Python для создания задач и напоминаний с графическим интерфейсом.

## Возможности

- Создание задач с названием, описанием и датой и временем.
- Настройка напоминаний до назначенного времени, в назначенное время и после него.
- Просмотр задач и фильтрация по статусу.
- Перенос напоминания на более позднее время.
- Завершение задачи с отменой оставшихся сигналов.
- Хранение задач в базе данных SQLite.

## Технологии

- Python
- Tkinter — графический интерфейс.
- SQLite — хранение данных.
- `datetime` — работа с датой и временем.

## Структура проекта

- `main.py` — запуск приложения.
- `gui.py` — графический интерфейс и обработка действий пользователя.
- `database.py` — работа с базой данных.
- `notifications.py` — системные уведомления.
- `requirements.txt` — зависимости проекта.
- `reminders.db` — локальная база данных, создаваемая приложением.

## Запуск

Из корневой папки учебного проекта выполни:

```powershell
python reminder_app\main.py
```

Если зависимости ещё не установлены, активируй виртуальное окружение и установи их:

```powershell
python -m pip install -r reminder_app\requirements.txt
```

## Примечание

Данные задач хранятся локально в SQLite. При переносе приложения на другой компьютер базу данных нужно перенести отдельно, если требуется сохранить созданные задачи.

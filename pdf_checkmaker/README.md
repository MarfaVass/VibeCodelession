# PDF-чек-мейкер

Консольная программа «PDF-чек-мейкер»: читает список товаров из CSV-файла,
заполняет HTML-шаблон отчета (Jinja2) и генерирует PDF-файл (WeasyPrint)
с итоговой суммой заказа. После успешной генерации PDF автоматически
открывается в стандартной программе просмотра документов Windows.

## Структура проекта

```
pdf_checkmaker/
├── pdf_generator.py              # Основной скрипт генерации PDF
├── requirements.txt              # Зависимости Python
├── README.md                     # Эта инструкция
├── OFFER.md                      # Оффер для фриланс-биржи
├── PROMPT.md                     # Промпт создания проекта (восстановленный)
├── data/
│   └── products.csv              # Входные данные (список товаров)
├── templates/
│   └── product_report.html       # HTML-шаблон отчета (Jinja2)
└── output/
    └── product_report.pdf        # Результат генерации (создается скриптом)
```

## Формат входных данных

Файл `data/products.csv` должен иметь заголовок с тремя обязательными колонками:

```csv
product,price,qty
Смартфон Samsung Galaxy A55 5G,26999,3
Внешний жесткий диск 2 ТБ USB 3.0,8590,2
```

- `product` — название товара (текст, может быть длинным — в PDF переносится);
- `price` — цена за единицу, число (десятичный разделитель — точка или запятая);
- `qty` — количество, число больше нуля.

Кодировка файла — UTF-8 (поддерживается также Windows-1251).

## Установка зависимостей

В проекте уже есть виртуальное окружение `venv` в корне проекта
(`C:\Users\fedan\OneDrive\Desktop\VIBE-Coder\Курс\venv`). Устанавливать
зависимости нужно именно в него.

Откройте PowerShell **в корне проекта** и выполните:

```powershell
# 1. Активировать существующее виртуальное окружение
.\venv\Scripts\Activate.ps1

# 2. Установить зависимости из requirements.txt
pip install -r pdf_checkmaker\requirements.txt
```

Альтернатива без активации окружения (тоже из корня проекта):

```powershell
.\venv\Scripts\python.exe -m pip install -r pdf_checkmaker\requirements.txt
```

Если PowerShell не дает запустить `Activate.ps1` (ошибка исполнения
скриптов), разрешите выполнение локальных скриптов один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

или просто используйте второй вариант с прямым путем к `python.exe`.


Либо без активации, из любой папки:

генерации файл автоматически откроется в стандартной программе просмотра
документов Windows.

## Важная особенность WeasyPrint на Windows

WeasyPrint — Python-библиотека, но для работы ей нужны системные
библиотеки **GTK / Pango** (`libpango`, `libgobject`, `libcairo`,
`gdk-pixbuf` и др.), которые не входят в состав Windows и не устанавливаются
через `pip`. На Linux и macOS они обычно уже есть; на Windows их нужно
поставить отдельно, иначе при запуске будет ошибка вида:

```
OSError: cannot load library 'libgobject-2.0-0.dll' ... 'gobject-2.0-0': The specified module could not be found.
```

Варианты решения:

1. **MSYS2 (рекомендуется):**
   - Установите MSYS2 с сайта https://www.msys2.org/
   - В терминале MSYS2 выполните: `pacman -S mingw-w64-ucrt-x86_64-pango`
   - Добавьте папку `C:\msys64\ucrt64\bin` в переменную окружения `PATH`
     (Параметры Windows → Система → О системе → Дополнительные параметры
     системы → Переменные среды).
   - Перезапустите PowerShell и запустите скрипт заново.

2. **GTK3 runtime installer:** установите сборку GTK3 runtime для Windows,
   например с https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer
   (устанавливает нужные DLL и прописывает PATH).

Если при запуске появится указанная ошибка — значит, проблема именно
в системных библиотеках GTK, а не в коде скрипта или зависимостях pip.

## Обработка ошибок

Скрипт проверяет данные и выводит понятные сообщения на русском языке
(и завершается с кодом 1), если:

- CSV-файл не найден или не читается (неверная кодировка);
- отсутствуют обязательные колонки `product`, `price`, `qty`;
- название, цена или количество не заполнены (указывается номер строки);
- цена или количество — не число;
- цена отрицательная или количество меньше либо равно нулю;
- в файле нет ни одной строки с данными;
- не установлены Jinja2 или WeasyPrint (с подсказкой, как установить).

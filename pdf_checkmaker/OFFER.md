# Оффер для фриланс-биржи

**Автоматизирую создание PDF-документов из ваших данных: прайс-листы, накладные, отчеты.**
Вы предоставляете таблицу в CSV (например, выгрузку из 1С, Excel или CRM), а я настраиваю
Python-скрипт, который за секунды превращает её в аккуратный готовый PDF с вашим
оформлением — больше никаких ручных наборов документов в редакторе. Скрипт проверяет
данные и сообщает о понятных ошибках, корректно работает с кириллицей и на Windows,
а готовые файлы открываются автоматически. Это идеальное решение для малого бизнеса,
маркетплейс-селлеров и менеджеров, которые регулярно готовят однотипные документы.

*Оффер составлен по результатам домашнего проекта «PDF-чек-мейкер» и описывает только
реализованную в нем функциональность: чтение CSV → заполнение HTML-шаблона (Jinja2) →
генерация PDF (WeasyPrint) с проверкой данных и автооткрытием файла.*

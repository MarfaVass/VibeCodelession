# Smart Body Academy — VK-бот

Виртуальный помощник сообщества ВКонтакте [Smart Body Academy](https://smartbodyacademy.ru/) («Академия умного тела» Андрея Новикова). Бот отвечает на вопросы по фактам из встроенной базы знаний (RAG + локальная модель Ollama) и принимает предварительные заявки в SQLite.

> Подробный отчёт по проекту (ДЗ № 06): [`reports/homework_06_bot_vk/homework_06_bot_vk.md`](../reports/homework_06_bot_vk/homework_06_bot_vk.md)

## Четыре направления

Бот работает с четырьмя направлениями академии — у каждого своя база знаний и своя анкета заявки:

- **Обучение на инструктора Pilates** — программа, опыт, формат обучения;
- **Обучение команды клуба / студии** — преподаватели выезжают на территорию заказчика;
- **Международные семинары** — фиксированная справка и анкета на английском (без LLM);
- **Персональные тренировки** — форматы: студия, онлайн, выезд.

Направление выбирается **только кнопкой** в главном меню — модель не угадывает категорию по тексту.

## Возможности

- Приветствие и меню из четырёх направлений; команды `/start`, `/menu`, `/help`, `/cancel`, `/book`;
- Ответы на вопросы только по базе знаний (10 документов, RAG-поиск фрагментов); нет данных — честный отказ, без выдумок;
- Пошаговая заявка с подтверждением; обязательны имя и контакт, необязательные поля можно пропустить;
- Попутный вопрос во время анкеты не сбрасывает заявку — бот отвечает и возвращает к анкете;
- Переключение направления подтверждается отдельно, чтобы не потерять ответы;
- Заявки сохраняются в SQLite со статусом `preliminary` / `processed` / `cancelled`;
- Ошибки Ollama (не запущена, таймаут, HTTP) не роняют бота — клиенту объясняют, что случилось, и предлагают оставить заявку или написать напрямую.

## Модель и технологии

- **Ollama**, модель **qwen2.5:3b-32k** — компактная локальная LLM (CPU, лимит ~150 токенов на ответ);
- Python 3.14, vkbottle 4.11 (long polling, кнопки), requests, sqlite3, python-dotenv;
- pytest + pytest-asyncio — 89 автотестов.

## Установка и запуск

Требуется Python 3.12+ и установленный [Ollama](https://ollama.com) с моделью `qwen2.5:3b-32k`.

```bash
cd pilates_vk_bot
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt      # Windows
# .venv/bin/pip install -r requirements.txt        # Linux/macOS
```

Файл `.env` в корне проекта (не коммитится):

```ini
VK_TOKEN=vk1.a....           # ключ сообщества VK, право «Управление сообщениями»
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:3b-32k
DB_PATH=data/bookings.db     # необязательно
AI_TIMEOUT=90                # необязательно
AI_MAX_TOKENS=150            # необязательно
```

Запуск:

```bash
.venv/Scripts/python -m bot.main
```

## Тесты

```bash
.venv/Scripts/python -m pytest    # 89 passed
```

Тесты не требуют VK-токена; «живые» тесты Ollama пропускаются, если сервис не запущен.

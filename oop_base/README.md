# OOP_base

Учебная консольная система управления задачами Todo на Python, созданная
в рамках домашнего задания VPb04 «Основы объектного мышления».

Назначение проекта — продемонстрировать базовое объектно-ориентированное
мышление: три связанных класса, каждый отвечает за свои данные и действия,
объекты взаимодействуют через методы, а не через прямой доступ к данным.

## Возможности

- создание пользователя и его проектов;
- добавление и удаление проектов;
- создание задач внутри проекта с названием, описанием и необязательным сроком;
- изменение описания и срока задачи, изменение статуса (`todo` — `in_progress` — `done`);
- поиск задач и проектов по ID;
- фильтрация задач по статусу;
- подсчет прогресса проекта (процент выполненных задач; пустой проект — 0%);
- проверка входных данных с понятными сообщениями об ошибках (`ValueError`, `KeyError`).

## Используемые классы

| Класс | Отвечает за | Основные методы |
|---|---|---|
| `User` | пользователь системы и его список проектов | `create_project`, `add_project`, `remove_project`, `get_project_by_id`, `find_project_by_name` |
| `Project` | проект и его список задач, генерация ID задач, прогресс | `add_task`, `remove_task`, `get_task_by_id`, `mark_task_status`, `complete_task`, `find_tasks_by_status`, свойство `progress` |
| `Task` | отдельная задача: название, описание, срок, статус | `change_description`, `change_due_date`, `set_status`, `complete`, свойства `id`, `title`, `description`, `due_date`, `status`, `info` |

Подробное техническое задание — в [architecture.md](architecture.md).

## Требования

- Python 3.10 или новее (проверено на Python 3.12).
- Дополнительные библиотеки не требуются — только стандартная библиотека.
- Нет базы данных, GUI и сторонних пакетов: данные хранятся в памяти.

## Запуск

Из папки `oop_base/` в терминале VS Code или PowerShell:

```powershell
cd oop_base
python main.py
```

Программа сама выполнит демонстрационный сценарий: создаст пользователя,
проекты и задачи, покажет изменение описания и срока, смену статусов,
расчет прогресса, поиск и удаление объектов, а также обработку
некорректных данных.

## Запуск тестов

Из папки `oop_base/`:

```powershell
python -m unittest
```

Для подробного вывода по каждому тесту:

```powershell
python -m unittest -v
```

## Ограничения

Данные не сохраняются между запусками программы (нет файлов и базы данных) —
это осознанное ограничение учебного проекта.

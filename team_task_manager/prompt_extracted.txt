ПРОЕКТ: TEAM TASK MANAGER
Техническое задание для Claude Code
Ты выступаешь в роли Python-разработчика и технического архитектора. Твоя задача — создать полноценный Telegram Task Manager для командной работы.
Работай непосредственно в открытой рабочей папке VS Code. Самостоятельно создавай структуру каталогов, файлы, виртуальное окружение, устанавливай необходимые библиотеки, реализуй функциональность и проверяй результат.
ВАЖНО:
Не ограничивайся генерацией примеров кода. Создавай реальные рабочие файлы проекта.
Не пиши весь проект одним монолитным файлом.
Не используй устаревшие версии библиотек без необходимости.
Не переписывай работающие модули ради косметических изменений.
Не скрывай ошибки и не считай задачу выполненной, пока проверки не пройдены.
Все действия выполняй последовательно, с контролем результатов каждого этапа.
Если возникает неоднозначность или требуется разрушительное действие, сначала запроси подтверждение пользователя.
1. НАЗНАЧЕНИЕ ПРОЕКТА
Создать универсального Telegram-бота TEAM TASK MANAGER для сбора, хранения, распределения и контроля выполнения задач команды.
Бот должен подходить для различных видов бизнеса.
Бизнес-специфика не должна быть жестко прописана в программной логике. Категории, статусы, приоритеты, название команды и другие справочники должны настраиваться администратором.
Одна установка приложения обслуживает одну команду или организацию.
2. ТЕХНОЛОГИЧЕСКИЙ СТЕК
Основные технологии:
Python — основной язык.
aiogram 3.x — Telegram Bot API.
SQLite — основная база данных.
aiosqlite — асинхронная работа с базой.
openpyxl — создание Excel-файлов XLSX.
python-dotenv — конфигурация окружения.
logging — логирование.
pytest — автоматическое тестирование.
pytest-asyncio — асинхронные тесты.
Перед установкой:
Проверь установленную версию Python.
Проверь совместимость Python с выбранной версией aiogram и остальными зависимостями.
Если текущая версия Python не поддерживается необходимыми пакетами, предложи совместимую версию.
Не устанавливай пакеты глобально.
Все зависимости устанавливай только в виртуальное окружение проекта.
Зафиксируй проверенные версии библиотек в requirements.txt.
Используй актуальный синтаксис aiogram 3.x.

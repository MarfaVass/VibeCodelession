# 🔐 Password Manager — локальный менеджер паролей

Учебный Python-проект: генерация надежных паролей, хранение учетных записей в локальной базе данных и шифрование сохраненных паролей.

## О проекте

Password Manager — консольное приложение, которое объединяет два сценария:

- **Создание учетной записи:** указать сервис и логин, сгенерировать пароль автоматически, настроить параметры генерации или ввести собственный пароль, а затем сохранить запись.
- **Генерация без сохранения:** получить пароль для использования вне менеджера, не добавляя его в базу данных.

Проект развивался в два этапа: от базового менеджера с генератором до приложения с объединенным сценарием создания учетной записи, настраиваемой генерацией и автоматическими тестами.

## Технологии

- **Python** — логика приложения и консольный интерфейс.
- **SQLite** — локальная база данных.
- **Fernet / cryptography** — шифрование сохраненных паролей.
- **Werkzeug** — функции для безопасного хеширования мастер-пароля.
- **unittest** — автоматические тесты.

## Запуск проекта

Требуется установленный Python и PowerShell или другой терминал.

### 1. Перейти в папку проекта

Из корневой папки репозитория:

```powershell
cd password_manager
```

### 2. Создать виртуальное окружение

Если оно еще не создано:

```powershell
python -m venv .venv
```

Активировать его в PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Установить зависимости

```powershell
python -m pip install cryptography werkzeug
```

### 4. Запустить приложение

```powershell
python password_manager.py
```

При первом запуске приложение может предложить настроить мастер-пароль. При последующих запусках потребуется пройти аутентификацию.

## Команды приложения

После запуска доступно меню:

| Команда    | Назначение                          |
| ---------- | ----------------------------------- |
| `create`   | Создать учетную запись              |
| `generate` | Сгенерировать пароль без сохранения |
| `get`      | Получить сохраненную запись         |
| `list`     | Показать список сервисов и логинов  |
| `delete`   | Удалить учетную запись              |
| `exit`     | Завершить работу                    |

### Создание учетной записи

Команда `create` запрашивает название сервиса и логин. Затем пользователь выбирает один из трех вариантов:

1. Автоматическая генерация пароля.
2. Настройка параметров генерации.
3. Ввод собственного пароля.

Перед сохранением приложение показывает подготовленные данные и запрашивает подтверждение. Сохраненный пароль шифруется.

### Генерация без сохранения

Команда `generate` предлагает быструю генерацию или настройку параметров. Полученный пароль выводится в терминал, но не добавляется в базу данных.

## Тестирование

Для запуска автоматических тестов из папки `password_manager`:

```powershell
python -m unittest discover -s tests -v
```

В текущей версии успешно пройдены **22 теста**: 15 тестов генератора и 7 тестов операций с базой данных и создания учетной записи.

Проверяются длина пароля, состав символов, ограничения генерации, добавление и получение записей, защита от дублирования сервиса, удаление и отказ от сохранения.

## Безопасность и ограничения

Это учебный проект, предназначенный для изучения Python, работы с базой данных, шифрования, тестирования и организации кода.

- Не используйте его как единственное хранилище критически важных паролей.
- Не публикуйте мастер-пароль, ключ шифрования, базу данных или реальные пароли.
- Файл ключа `.key` и база `password.db` должны оставаться защищенными и исключенными из Git.
- Потеря ключа может сделать сохраненные данные недоступными.
- Шифрование базы не защищает от всех угроз, например от вредоносного ПО на компьютере или доступа к разблокированному приложению.
- Перед использованием на реальных данных необходимы дополнительные проверки безопасности.

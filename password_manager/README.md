# CLI-менеджер паролей (учебный проект)

Локальное приложение на Python: мастер-пароль, список учётных записей, шифрование паролей через Fernet и генерация случайных паролей.

## Возможности

- Первый запуск предлагает задать мастер-пароль; его хэш хранится в SQLite.
- Команды `add`, `get`, `list`, `delete`, `new`, `exit`.
- Сохранённые пароли шифруются Fernet; в списке показываются только сервисы и логины.
- Генерация паролей длиной 12–64 символа.
- Дополнительный параметр генерации исключает похожие символы `0/O`, `l/I`, `1`.
- SQLite-файл и ключ создаются автоматически.

## Запуск в Windows PowerShell

Из папки проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python .\password_manager.py
```

При первом запуске задайте мастер-пароль длиной не менее 12 символов. Ввод скрыт.

## Проверка команд

1. `new` — сгенерировать пароль.
2. `add` — добавить сервис, логин и пароль (оставьте поле пароля пустым, чтобы сгенерировать его).
3. `list` — показать названия сервисов и логины.
4. `get` — получить сохранённый пароль по названию.
5. `delete` — удалить запись.
6. `exit` — выйти.

Для демонстрации используйте только вымышленные тестовые данные. Не вводите реальные пароли от Gmail, Telegram, банков и других сервисов.

## Важное замечание о безопасности

Это учебный пример, а не замена проверенному менеджеру паролей. Файл `.key` нужен для расшифровки данных: если потерять его, сохранённые пароли нельзя будет восстановить; если злоумышленник получит и базу, и ключ, он сможет расшифровать записи. Храните файлы в защищённой локальной папке и не отправляйте `password.db` или `.key` в GitHub.

Для мастер-пароля используется PBKDF2-HMAC-SHA256 с солью и большим числом итераций, а не простой SHA-256. Это безопаснее для хранения паролей. Используйте длинную уникальную фразу.

## Файлы

- `password_manager.py` — CLI, генерация паролей, аутентификация.
- `password.db` — создаётся при запуске, игнорируется Git.
- `.key` — ключ шифрования, создаётся при запуске, игнорируется Git.
- `requirements.txt` — зависимости.

# Домашнее задание: CLI-менеджер паролей

## Цель
Создать локальное консольное приложение на Python для хранения учётных записей, шифрования паролей и генерации новых случайных паролей.

## Реализовано
- SQLite-хранилище для учётных записей.
- Мастер-пароль с проверкой при запуске; хранится стойкий PBKDF2-хэш с солью.
- Шифрование сохранённых паролей с помощью Fernet.
- Команды `add`, `get`, `list`, `delete`, `new`, `exit`.
- Генерация случайных паролей длиной 12–64 символа.
- Дополнительная опция исключения похожих символов `0/O`, `l/I`, `1`.
- README с установкой, запуском, проверкой и ограничениями безопасности.
- `.gitignore` исключает базу паролей, ключ шифрования, виртуальное окружение и служебные файлы.

## Запуск
См. команды в `README.md`. Приложение рассчитано на запуск из PowerShell в Windows.

## План ручной проверки
1. Установить зависимости и запустить приложение.
2. Создать мастер-пароль из тестовой фразы.
3. Выполнить `new`, проверить длину и отсутствие похожих символов при включённой опции.
4. Выполнить `add`, добавив вымышленный сервис, логин и тестовый пароль.
5. Выполнить `list`: должны отображаться только названия и логины.
6. Выполнить `get`: пароль должен расшифроваться и отобразиться.
7. Выполнить `delete`, затем `list`: удалённая запись должна отсутствовать.
8. Завершить работу через `exit`.

## Безопасность
Использовать только вымышленные данные для учебной демонстрации. Не загружать в репозиторий `password.db` и `.key`. Потеря ключа означает потерю доступа к зашифрованным записям. Если ключ и база попадут к третьему лицу одновременно, данные могут быть расшифрованы. Это учебная реализация, не замена профессиональному менеджеру паролей.
